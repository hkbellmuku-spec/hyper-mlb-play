# Team Dynasty

iPhoneのブラウザで遊べる野球ゲーム。

- 遊ぶ: GitHub Pages のURLを開くだけ(ホーム画面に追加するとアプリのように遊べます)
- ドラフト対戦: ホームの「DRAFT」から。CPUとも、友だちとオンラインでも
- オンライン対戦: ホーム →「オンライン対戦」→ 部屋を作って番号を相手に送る(登録不要)

Created by Kota.Saito
